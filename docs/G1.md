# G1 — DSL ve gerçek token karşılaştırması

Ders PDF'sinin 12. sayfasındaki iki ifade değiştirilmeden ölçüldü.

- Model referansı: GPT-4o
- Tokenizer: OpenAI `o200k_base`
- Ölçüm aracı: `tiktoken` 0.14.0
- Ölçüm tarihi: 15 Ekim 2026
- Kapsam: yalnız aşağıdaki kod metni; sohbet rolleri, mesaj zarfı ve sistem prompt'u dahil değil

| Yığın | Ölçülen kod | Token sayısı | Token kimlikleri |
|---|---|---:|---|
| Python | `from datetime import datetime, timedelta` + satır sonu + `datetime.now() - timedelta(weeks=1)` | 17 | `2845, 19826, 1588, 19826, 11, 105969, 198, 34392, 20633, 416, 533, 105969, 7, 159699, 28, 16, 8` |
| Ruby + ActiveSupport | `1.week.ago` | 4 | `16, 108522, 13, 6334` |

Bu örnekte Ruby ifadesi 13 token daha kısa ve Python örneğinin yaklaşık %24'ü kadar token kullanıyor. Bu, tek görev ve tek tokenizer sonucudur; Ruby'nin bütün görevlerde daha ucuz olduğunu kanıtlamaz. PDF'nin vurguladığı güvenilir çıkarım yazma hızından çok doğrulama kolaylığıdır: `1.week.ago` İngilizce niyet sırasına yakındır, fakat Türkçe niyetle 1:1 olduğu iddia edilmez.
